# discord-server-proxy-bot
Bot for discord for proxying connection to server

Have you ever had a problem when you cannot access discord because of some firewall or any other way that restricts access to your discord server?

This is a solution, this bot servers as a proxy to your server

## Features
- User prefixes
- Admin panel with authorized discord user id with discord oauth where you are able to create accounts to your bot
- Send / Read messages
- Chat History
- Upload files
